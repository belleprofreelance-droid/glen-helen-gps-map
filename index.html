Field mode

  1. Open this app once before leaving home so the map image gets cached.
  2. At Glen Helen, wait for GPS accuracy to settle before saving points.
  3. Prefer fixed landmarks: signs, bridges, trail junctions, building corners, parking edges.
  4. Collect at least 6–10 spread-out points. Avoid saving several points clustered in one area.
  5. Use notes that describe the exact physical spot you stood on.
  6. Export or copy JSON before clearing browser storage.

Build notes

This app uses the Google Earth KMZ overlay bounds as an initial approximation. Field control points are still needed before trusting the dot on trail intersections.
